# 📚 Online Coaching / Book Management System

An ASP.NET Core MVC web application for managing **books, categories, authors, users, carts, rentals, and sales** with a clean **Admin Dashboard**.  
It also includes a **client registration flow** where new users are prompted to complete their profile after signing up.  

---

## ✨ Features

### 👨‍💻 User Side
- User Registration & Login (Identity-based authentication)
- Profile completion popup for new clients
- Browse available books
- Add books to cart
- Rent or purchase books
- Responsive UI (Bootstrap 5 + custom styles)

### 🔧 Admin Dashboard
- Sidebar-based admin layout
- Manage **Categories, Authors, Books, Users**
- View and manage **Carts, Rentals, Sales**
- Add new **Admins & Receptionists**
- Integrated **Logout & Settings** panel
- Footer included with social links

---

## 🛠️ Tech Stack
- **ASP.NET Core MVC** (.NET 6/7/8)
- **Entity Framework Core** (Code-First with Migrations)
- **Identity** for authentication & roles
- **AutoMapper** for mapping DTOs and models
- **Bootstrap 5** & **Font Awesome** for styling
- **SQL Server** (default, can be switched)
